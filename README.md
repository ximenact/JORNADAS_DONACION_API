# 🩸 API de Jornadas de Donación de Sangre

API REST desarrollada con **Python y FastAPI** para administrar jornadas de donación de sangre y usuarios, utilizando PostgreSQL como sistema de gestión de bases de datos.

## 📌 Descripción

El proyecto permite gestionar jornadas de donación de sangre mediante operaciones CRUD (crear, consultar, actualizar y eliminar). También cuenta con un módulo independiente para la administración de usuarios.
La API está organizada mediante una arquitectura por capas, facilitando la separación de responsabilidades y el mantenimiento del código.

## 🚀 Tecnologías utilizadas

- **Python:** lenguaje de programación.
- **FastAPI:** desarrollo de la API REST.
- **PostgreSQL:** sistema de gestión de bases de datos.
- **Neon:** alojamiento de la base de datos PostgreSQL.
- **SQLAlchemy:** interacción con la base de datos.
- **Pydantic:** validación de datos.
- **pwdlib:** generación de hashes seguros para las contraseñas.
- **Git y GitHub:** control de versiones.
- **Render:** despliegue de la aplicación.
